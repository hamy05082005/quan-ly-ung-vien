Improve visual quality of an **existing** page. Do not rebuild from scratch unless asked.

## Checklist

- Clear visual hierarchy (one primary CTA)
- Consistent spacing rhythm
- Readable type scale on mobile
- Real imagery when student provides assets; otherwise labeled Sample placeholders
- Avoid purple-gradient / generic AI aesthetic defaults
