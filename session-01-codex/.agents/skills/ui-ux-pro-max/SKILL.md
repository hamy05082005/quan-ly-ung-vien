When the student is stuck on **visual direction**, propose 1–2 concrete options:

- Color palette (3–5 tokens)
- Font pairing (display + body)
- Layout pattern for the landing (hero → value → proof → CTA)

Write choices into `docs/design-guidelines.md` before coding.
