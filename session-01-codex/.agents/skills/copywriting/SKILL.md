Write short conversion copy aligned to `docs/project-overview-pdr.md`.

## Rules

- Prefer concrete benefits over buzzwords
- One idea per headline
- CTA = verb + outcome (e.g. "Đăng ký tư vấn miễn phí")
- Match UI language in the PRD (usually Vietnamese)

```
Follow .agents/skills/copywriting/SKILL.md
Write hero headline + subhead + primary CTA for [product] in Vietnamese.
```
